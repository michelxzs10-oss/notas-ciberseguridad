## Comandos y herramientas

| Comando | Para qué sirve | Ejemplo |
|---|---|---|
| `ls` | Listar archivos de un directorio | `ls -la /var/log` |
| `cd` | Cambiar de directorio | `cd /etc` |
| `cat` | Mostrar el contenido de un archivo | `cat notas.txt` |
| `find` | Buscar archivos por nombre | `find / -name "*.log"` |
| `grep` | Buscar texto dentro de archivos | `grep "Failed" auth.log` |

## Cómo se relaciona con el trabajo en un SOC

Un analista revisa logs constantemente. Con grep puedo filtrar intentos fallidos de inicio de sesión en un archivo de miles de líneas.
